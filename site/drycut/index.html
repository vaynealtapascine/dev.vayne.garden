DryCut

Private, local background removal for Windows, macOS and Linux. Your images never leave your computer.

Download for Windows Other downloads

What it does

  • Fast by defaultAn included, quantized IS-Net model handles everyday images offline.
  • Stronger when neededDownload the optional BiRefNet model in Settings for hair, fur and busy backgrounds.
  • Edges your wayNone, Soft, Balanced or Detailed cleanup, and reprocess without reopening the image.
  • BatchesQueue several images, see the time remaining, and work through results in the gallery.
  • Easy to reachDrag and drop, paste with Ctrl+V, or right-click an image in Explorer on Windows.
  • Panel modeShrink it to a narrow side panel and pin it on top beside another app.

Get it

  • Windows installerPer-user, no admin needed
  • Windows portable ZIPExtract fully, then run DryCut.Desktop.exe
  • macOS, Apple siliconPortable ZIP
  • macOS, IntelPortable ZIP
  • Linux x64Portable ZIP

Version 1.0.0. The builds aren't code-signed, so Windows SmartScreen may warn about an unrecognized app. GPU acceleration (DirectML) and Explorer integration are Windows-only; other platforms run on the CPU. The only network request DryCut makes is the optional download of the stronger model, and only when you ask for it. Checksums and release notes.
