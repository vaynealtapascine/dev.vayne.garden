A few useful things to know

Before you begin.

What exactly is a workskin?

A workskin is a stylesheet attached to an AO3 work. It styles your chapter content—messages, letters, headings, and more. The chapter’s HTML supplies the structure; the skin supplies the appearance.

Do I need to know HTML or CSS?

These examples give you a working starting point, with separate modules for content and styles. You can replace the text first, then make small changes while watching the preview. More involved designs may need some HTML and CSS knowledge.

Can readers turn the formatting off?

AO3 readers can hide the creator’s style. These templates keep names, dates, meaningful labels, and line breaks in HTML, rather than relying on color or generated decoration. Check your own finished fic with the style hidden, too.

Where does my work go?

EO3 saves your work in this browser. Download a document with the editor’s “save” control to keep a portable backup. Clearing browser data can remove local saves. Modules that load external URLs make their own network requests.

Can I mix examples in one fic?

Yes. Each template uses distinct class names, so you can combine their HTML and CSS. Keep footnote anchor names unique within a chapter, and test the combined work in the editor and on AO3.

What is in the download?

All 14 examples as editable EO3 documents, matching chapter HTML fragments, workskin CSS, a usage guide, and the MIT license. The gallery previews come from those same documents. There are no external images or fonts to host.
