Arbor

A self-hosted outliner for tracking projects: nested items, your own statuses and tags, notes, saved views, templates, and a phone app that works offline.

Run it yourself Source on GitHub

What it does

  • Entry with no frictionType and press Enter. #tag, @status, :: for a note, /template for a whole sub-tree.
  • Real outliner editingTab to nest, drag to move, Ctrl+Enter to finish, and undo for every change.
  • Statuses and tags you defineAny name, colour and icon. Tags nest, so #work/client-a is found under #work.
  • Search that understands you(@done OR @to-do) AND #writing, phrases, exclusions, then keep it as a saved view.
  • NotesFull markdown under any item, with tickable task lists and images.
  • Works offline on your phoneInstall it as an app; changes queue and sync when you're back on your network.

Run it yourself

Arbor is a small Node server with a SQLite file and no outside services. It needs Node 22.13 or newer.

git clone https://github.com/vaynealtapascine/Arbor.git
cd Arbor
npm install
npm run dev

That opens a development copy at localhost:5241 with a short tour to play with. The README's Run it for real section covers installing it properly on your own machine and reaching it from your phone.
